评测口径与项目范围

基于开源 SmolVLA、LeRobot 与 LIBERO 的个人工程项目。100 条训练、25 条留出轨迹；默认专家与 LoRA 各训练 5,000 步。三组配置各在 5 个固定任务中评测 100 回合，仅一个训练种子。

42.5% 指同观测、batch=1、RTX 4090 上 FP16 动作块生成中位时延降幅，包含模型内部图像准备，排除外部 processor、仿真与完整机器人墙钟响应。76%→76% 是本次固定评测结果，不证明统计无损或全新场景泛化。

LoRA 配方学习率与默认组不同，属于实用配置比较。采样减步是既有采样器的工程优化，未提出原创 VLA 架构，未进行真机部署。完整逐任务结果、Wilson 区间、原始计时与全部视频见技术材料。
